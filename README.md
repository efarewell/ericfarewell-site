# ericfarewell.com

Static site for Eric Farewell. Watercolor and Peacock design system.
Auto-deploys to Cloudflare Pages on push to `main`.

- Primary path: homepage, Guided Start, Work with Eric, Royals, private coaching, speaking, writing, and the Royals Time Audit
- Shared styles: assets/css/tokens.css (design tokens) + assets/css/site.css
- Shared JS: assets/js/site.js
- No build step. Output = repo root.

Private review pages and unfinished access-gated tools are excluded in `.gitignore`. Do not force-add them without checking for client evidence, transcript links, or browser-only access controls.
