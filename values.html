The Core Values Exercise

Core values that reflect who's actually there.

Aspirational values don't change behavior or people. Even when they feel within reach, they often backfire because they don't reflect who's actually there. This is the exercise I use instead, and I've run it on Freedom Accelerator and Royals calls for the last eighteen months.

Open the exercise What it leaves you with
How it goes

I'm not going to tell you how it works.

I'd rather you experience it. It starts with a few hard stories about the people who cost you the most, and it takes about twenty minutes. Somewhere in the middle it turns, and that turn is the reason I don't explain it first.

I can tell you what's on the other side.

  1. 01No more than five core values, named in your own words.
  2. 02What each one means, and what it looks like when someone is living it.
  3. 03The order they go in when two of them pull against each other.

For me, once the values, the vision, and the mission are defined, everything else comes from that. This work tells me who to hire next and which pieces need to be let go of.
